```bash
    --comparison-fp-prefix /sf/data \
    --vendor bloomberg --dataset bbocax_cwiq_pipe --version 1.0 \
    --output /tmp/time_report.txt
```

### Flags

| Flag | Description |
|------|-------------|
| `--comparison-fp-prefix` | CDP reference files path (e.g., `/sf/data`) |
| `--vendor` | Vendor name |
| `--dataset` | Dataset name |
| `--version` | Dataset version |
| `--hours` | Scan window in hours (default: 4) |
| `--fp-prefix` | Data Alchemy output prefix (default: `FP_PREFIX` env) |
| `--output` | Write report to file instead of stdout |
