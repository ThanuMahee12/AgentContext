## Discussion #2: Roadmap Update

**Link:** https://github.com/DataTrekLabs/pathseeker/discussions/2

### Path Analysis = End-to-End Scope

```
Path Analysis (Full Scope)
├── Path String Analysis
│   ├── Segment parsing (LITERAL, DIGITS, VARIABLE, FILE_EXT)
│   ├── Glob pattern extraction
│   └── Regex pattern extraction
│
└── Path Metadata Analysis
    ├── Timestamps (mtime, ctime, atime)
    ├── Size & type (size, mimetype)
    ├── Extensions (suffixes)
    ├── Permissions (ACL, mode)
    └── Attributes (hidden, readonly, etc.)
```

### Schema Fields
| Field | Type | Description |
|-------|------|-------------|
| `path` | string | Relative path |
| `type` | enum | file, directory, archive, symlink |
| `mtime` | datetime | Modification time |
| `size` | int | File size (bytes) |
| `mimetype` | string | MIME type |
| `compression` | enum | gzip, bz2, xz, zst, zip |
| `archive_type` | enum | tar, zip, 7z |
| `content` | array/string | Nested items or file content |
