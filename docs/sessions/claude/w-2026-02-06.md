### 1. Python Virtual Environment
- Correct command: `python -m venv <venv_name>` (not `python venv -m venv`)
- If pip installs to system instead of venv, use `./venv/bin/pip` or `python -m pip`

### 2. rsync with Relative Path Structure
Syncing files while preserving folder structure using `--relative` and `./` marker:

```bash
rsync -av --relative /sf/data/./msci_barra/security_master/1.0/raw/2026/20260130/RiskFreeRate_*.lz4 /destination/
```

### 4. setfacl for ACL Permissions
Set regular + default ACL for svc_dat_alchemy user:

```bash
setfacl -R -m u:svc_dat_alchemy:rwx -m d:u:svc_dat_alchemy:rwx /sf/proj/data_alchemy/devData/alchmy_test_space
```

- `-R` - Recursive
- `-m u:USER:rwx` - Regular ACL (existing items)
- `-m d:u:USER:rwx` - Default ACL (inherited by new items)
- Verify with: `getfacl /path`
