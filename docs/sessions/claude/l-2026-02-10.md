### 5. Key Findings
- Files without date suffix (e.g., `file.cax`) are intermediate files - no mapping needed
- Files with date suffix (e.g., `file.cax.20251130`) are final files - have grabber map
- Systemd FILE_PATTERN with special chars needs double quotes
- Backslashes in `.cax` patterns cause systemd syntax errors - use `.cax` not `\.cax`
