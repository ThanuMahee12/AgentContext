### Key Learnings

#### --backfill vs --backfill-range
| Option | Filter Method | Use Case |
|--------|---------------|----------|
| `--backfill N` | mtime (hours ago) | Recent files |
| `--backfill-range YYYYMMDD:YYYYMMDD` | mtime within date range | Specific date window |

Both use **file mtime** for raw files in `env*/` directories.

#### Service Conflicts
When running manual backfill, **STOP the systemd service first** to avoid:
- Database conflicts (both writing to same sqlite)
- Race conditions on file processing
- Duplicate processing attempts
