## Issues Encountered

### 1. Jobs Stuck (Not Completing)

**Symptom:** Status stuck at X/Y, jobs disappear from queue without writing `.done`/`.failed`

**Cause:** Jobs killed by OOM or cluster limits before writing status

**Solution:**
1. Kill remaining jobs: `qdel -u $USER`
2. Run merge: `python -m data_census.scanner merge --output ...`
3. Enable timeout: `SGE_JOB_TIMEOUT=01:00:00`

### 2. DuckDB OOM During Merge

**Symptom:** `Out of Memory Error: Failed to allocate block`

**Cause:** Loading all 1000+ result files at once

**Solution:** Process in batches of 100 files

### 3. S3 Credentials Error

**Symptom:** `Unable to locate credentials`

**Solution:** Add `--profile meta_data_extract` or set `AWS_PROFILE` env var
