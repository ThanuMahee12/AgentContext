## Key Technical Learnings

### Pattern Matching Issue
- Original regex: `equityAsia1(?!.*(CorporateActions|\.cax))`
- Problem: `equityAsia1P` would match `equityAsia1PricingAdjustmentActions*`
- Solution: Use specific `equityAsia1Pricing.c` and `equityAsia1Pricing.p` patterns

### DQ Weekend Data
- Euro, Lamr, Namr, MifidEuro regions have no weekend data
- DQ shows "missing" files for weekends - this is expected behavior
