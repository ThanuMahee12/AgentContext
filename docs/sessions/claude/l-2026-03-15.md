## Athena Query (with _delta_log exclusion)

```sql
SELECT
    dtr.table_name,
    r.fullpath as raw_fullpath,
    r.pattern_id as raw_pattern_id,
    re.fullpath as enriched_fullpath,
    re.pattern_id as enriched_pattern_id
FROM data_census.raw r
JOIN data_census.lineage_mapping lm ON CAST(r.pattern_id AS VARCHAR) = lm.raw_pattern_id
JOIN data_census.delta_table_repo dtr ON lm.table_id = dtr.table_id
LEFT JOIN data_census.raw_enriched re ON CAST(re.pattern_id AS VARCHAR) = lm.enriched_pattern_id
    AND re.year = r.year AND re.month = r.month AND re.day = r.day
    AND re.fullpath NOT LIKE '%_delta_log%'
WHERE r.year = '2026' AND r.month = '03' AND r.day = '14'
    AND dtr.table_name LIKE '%equity_rpx%'
ORDER BY r.fullpath;
```
