## Feature: --ignore-db

### Behavior
| Flag | DB Check | Result |
|------|----------|--------|
| `--ignore-db` | Skip | Process ALL files from disk |
| `--backfill` | Check | Skip processed files |
| `--backfill-range` | Check | Skip processed files |
| No flags | Check | Skip processed files |

### Flow
```
Filesystem Layer (always runs first)
├── get_list_of_files()
├── --layer-from filter
├── --backfill (mtime filter)
├── --backfill-range (date filter)
├── --file-pattern (regex filter)
└── --file-patterns (multi-pattern)
         ↓
    files_to_process
         ↓
┌────────────────────────────────┐
│         --ignore-db?           │
├────────────────────────────────┤
│ YES → process ALL from disk    │
│ NO  → DB check                 │
└────────────────────────────────┘
```

## Feature: --layer-from

### Behavior
| Flag | Scans | Pipeline |
|------|-------|----------|
| `--layer-from bronze` (default) | `raw/` | raw → bronze → silver → gold |
| `--layer-from silver` / `-l silver` | `bronze/` | bronze → silver → gold |
| `--layer-from gold` / `-l gold` | `silver/` | silver → gold |

### Use Case
Crash recovery - restart pipeline from a specific layer.

### __NO_OUTPUT__ Placeholder
- Only lives in DB
- Prevents infinite reprocessing of unmapped files
- Not affected by `--ignore-db` (no DB = no placeholder)

### -newermt Flag
