
## Fix Details

### Root Cause (NFS)

**SQLite WAL mode does not work on NFS filesystem.**

```
WAL mode on NFS:
├── .sqlite-shm requires mmap() - broken on NFS
├── 12 workers cannot coordinate locks
├── WAL file grows (4MB), never checkpoints
├── Workers stuck in D state
└── busy_timeout expires → disk I/O error
```

### Changes Made

| File | Change |
|------|--------|
| `db.py` | WAL → DELETE journal, debug logging |
| `parallel.py` | Disk I/O error handling (4 locations) |

### Key Design Decisions

1. **Per-phase merge + clear** - No shard accumulation
2. **DuckDB lazy queries** - No context dict, no OOM
3. **Worker shards** - Each worker writes to `workers_db/w{id}.sqlite`

### Architecture

```
Bronze Start  → DuckDB query canonical (clean)

                ↓

...
```
