## Today's Work: NFS Fix

### Root Cause

**SQLite WAL mode does not work on NFS filesystem.**

```
WAL mode on NFS:
├── .sqlite-shm requires mmap() - broken on NFS
├── 12 workers cannot coordinate locks
├── WAL file grows (4MB), never checkpoints
├── Workers stuck in D state
└── busy_timeout expires → disk I/O error
```

### Fix Committed

**Commit:** `0e0f76d`
**Branch:** `feature/sqlite-parallel-part1-move-reads`
**MR:** https://git.codewilling.com/data/cwiq-pipe/data-alchemy/-/merge_requests/609

| File | Change |
|------|--------|
| `db.py` | WAL → DELETE journal, add debug logging |
| `parallel.py` | Handle disk I/O errors, mark for reprocessing |
