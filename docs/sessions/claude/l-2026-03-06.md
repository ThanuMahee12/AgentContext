## Root Cause Analysis

### Primary Root Cause

**SQLite WAL mode does not work on NFS filesystem.**

```
WAL mode requires:
├── .sqlite-shm file (shared memory via mmap)
└── mmap() system call for process coordination

NFS limitation:
├── mmap() doesn't work properly on network filesystem
├── .sqlite-shm cannot coordinate between processes
└── WAL checkpoint never executes
```

### Error Chain

```
WAL mode enabled on NFS
         ↓
SHM (shared memory) broken
         ↓
12 workers cannot coordinate locks
         ↓
WAL file grows (4MB), never checkpoints
         ↓
Lock contention → workers stuck in D state
         ↓
SQLite busy_timeout expires (30 sec)
         ↓
sqlite3.OperationalError: disk I/O error
```

### SQLite Files Evidence

```
$ ls -lah *.sqlite*

.sqlite      8K-344K   ← Main DB (small - data stuck in WAL)
.sqlite-wal  1.6M-4MB  ← WAL file (large - never checkpointed)
.sqlite-shm  32K       ← SHM file (broken on NFS)
```
