## Technical Details

### Confidence Score Calculation

```python
from difflib import SequenceMatcher

def similarity(a, b):
    a_norm = a.lower().replace('_', '').replace('-', '')
    b_norm = b.lower().replace('_', '').replace('-', '')
    return SequenceMatcher(None, a_norm, b_norm).ratio()
```
