## Issue: Staging Mode FILE_PATTERN Not Applied

### Root Cause
In staging mode, `create_sample_data.py` was creating ALL files from `tree.json` without applying FILE_PATTERN filter. This caused:
1. Race conditions - multiple services creating same files
2. Permission errors - `premarketPfdExch*` errors across all services
3. DES wrapper errors - services without `.cax` files trying to create DES wrapper

### Fix Applied
**File**: `data_alchemy/main.py` (lines 706-719)

```python
# Apply file_pattern filter to staging files (same as processing filter)
# This ensures each service only creates files matching its FILE_PATTERN
if file_pattern:
    pattern = re.compile(file_pattern)
    pre_filter_count = len(filepaths)
    filepaths = [
        (fp, mtime) for fp, mtime in filepaths if pattern.search(fp)
    ]
    logger.info(
        "File pattern '{}' filtered staging files: {}/{}",
        file_pattern,
        len(filepaths),
        pre_filter_count,
    )
```

## Key Learnings

1. **Staging mode requires FILE_PATTERN filter** - Without it, all services try to create all files from tree.json
2. **DES wrapper race condition** - Multiple services without .cax files were trying to create DES wrapper
3. **FILE_PATTERN vs FILE_PATTERNS** - Both work now; FILE_PATTERNS is comma-separated, converted to FILE_PATTERN with `|` join
