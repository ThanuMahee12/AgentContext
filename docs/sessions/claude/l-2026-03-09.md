- **Commit:** `ad07bb3` - "fix: add missing worker_context context manager"

```python
@contextmanager
def worker_context(worker_id: int) -> Generator[int, None, None]:
    """Context manager to temporarily set worker ID."""
    previous_id = get_worker_id()
    _set_worker_id(worker_id)
    try:
        yield worker_id
    finally:
        _set_worker_id(previous_id)
```
