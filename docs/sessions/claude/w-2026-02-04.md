### 1. PathSeek Project Review

Performed full codebase review of `C:\Users\thanu\Downloads\pathseek` (v0.3.0)

**Project Purpose:** CLI tool that extracts reusable regex/glob patterns from file paths

**Architecture:** Onion/Layered pattern
- `core/` - Pure functions (analyzer.py, enums.py)
- `models/` - Pydantic data models (PathNode, FileNode, SegmentAnalysis)
- `extractors/` - Business logic (glob_extractor.py, pattern_extractor.py)
- `infrastructure/` - CLI and filesystem I/O

**Key Features:**
- Directory scanning with depth limits
- Segment classification (DIGITS, LITERAL, FILE_EXT, VARIABLE, HIDDEN)
- Three glob modes: Simple (`*`), Medium (`????`), Advanced (`[0-9]`)
- Regex pattern generation with proper escaping
- Interactive CLI with rich formatting

**Tech Stack:** typer, rich, pydantic, python-magic, pyarrow, arrow

**CLI Commands:**
```bash
pathseek glob scan <path> -L 3 -m a
pathseek regex scan <path>
pathseek run  # interactive
```

**Docs:** https://thanumahee12.github.io/pathseek
