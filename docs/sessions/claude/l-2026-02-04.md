## Architecture Recap

```
src/pathseek/infrastructure/
├── cli.py       # Entry point, command loop
├── session.py   # Session state + JSON persistence
├── commands.py  # Command handlers (list, count, run, etc.)
└── display.py   # Logo, help display
```

**Commands:**
- Actions (no prefix): `list`, `count`, `filter`, `run`, `help`, `exit`
- Settings (with /): `/mode`, `/basepath`, `/format`, `/glob`, `/type`, `/depth`, `/output`, `/show`, `/save`, `/reset`
