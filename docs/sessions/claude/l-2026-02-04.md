## ACL Commands for Cross-User Copy

To allow `svc_dat_alche_u` to recursively copy from `/home/svc_dat_alchemy/assets`:

```bash
# Allow traversing the home directory
setfacl -m u:svc_dat_alche_u:x /home/svc_dat_alchemy

# Recursively grant read + execute on assets directory and contents
setfacl -R -m u:svc_dat_alche_u:rX /home/svc_dat_alchemy/assets

# Set default ACL for future files (optional)
setfacl -R -d -m u:svc_dat_alche_u:rX /home/svc_dat_alchemy/assets
```

**Notes:**
- `x` on home dir = traverse only (not list)
- `rX` = read + execute on directories (capital X), read on files
- `-d` = default ACL for new files
