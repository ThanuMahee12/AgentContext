#### 1. Bloomberg Decrypt Fix (MR !513)

**Branch:** `fix/bloomberg-decrypt-to-silver`

**Problem:** Bloomberg encrypted files (.enc) were being decrypted to bronze directory, polluting bronze with non-raw `.gz` files.

**Reviewer Comments (wingate.jones):**
1. "this creates a temporary gzip file, lets write bytes straight to disk"
2. "lets also log that is what we are doing before and after in case it is too big for memory"

**Solution - Minimal Fix Approach:**
- Reverted shell pipe approach (too complex, bypassed existing functions)
- Used existing `decrypt_bloomberg_file()` and `decompress_gz()` functions
- Changed output location: decrypt to silver .gz, decompress, cleanup intermediate file
- Added logging before/after with timing

**Files Changed:**
- `data_alchemy/handlers/handle_silver.py` - decrypt to silver, add logging with timing
- `tests/silver_tests.py` - updated test mocks

**Commit:** `da6aab3` - pushed to `fix/bloomberg-decrypt-to-silver`

**Key Decision:** Chose minimal fix (temp .gz in silver, cleaned up) over shell pipe approach because:
- Reuses existing tested functions
- No changes to `bloomberg_decrypt.py`
- Simpler, safer, fewer lines changed
