### Key Insight
Grabber map only routes files with date suffixes:
- `*.cax.20251130` -> `/sf/data/bloomberg/corporate_actions/2.0/raw/2025/YYYYMMDD/`
- Files without date suffixes skipped: `"No grabber-map for file, skipping (MOVE_PRODUCTION_FILES not set)"`

## Logging Context Issue (--log-prefix)

### Question
Can we add `--log-prefix` flag to capture logs per service?

### Current State
- **No `--log-prefix` flag exists** in the code
- Logging uses stdout/stderr only (loguru)
- Systemd handles log file separation via `StandardOutput/StandardError`

### Problem Found
Context variables are set **too late** - inside `init_db()` during file processing, not at startup.

**Code flow:**
```
1. main() starts
2. logger.info("Using backfill range...")     ← NO CONTEXT (no prefix)
3. logger.info("Discovering files...")        ← NO CONTEXT (no prefix)
4. ... file processing loop ...
5. init_db() called                           ← CONTEXT SET HERE (too late!)
   └── vendor_context.set(vendor)             # db.py:313
   └── dataset_context.set(ds)                # db.py:314
   └── db_name_context.set(formatted_db_name) # db.py:335
```

**Evidence in logs:**
```
# Early logs - NO prefix
2026-02-11 08:26:28 | INFO     | Using backfill range: 20251130 to 20251208
2026-02-11 08:26:28 | INFO     | Discovering files: bloomberg | bbocax_cwiq_pipe | 1.0 | ALL

# Later logs - HAS prefix (after init_db called)
2026-02-11 08:26:33 | INFO     | [bloomberg/bbocax_cwiq_pipe] Bronze: equityAsia1...
```

### Files Involved
- `data_alchemy/main.py` - CLI entry, logging config
- `data_alchemy/context.py` - Context variables defined
- `data_alchemy/utils/db.py:313-335` - Context set in `init_db()`

### Fix Required
To implement `--log-prefix` correctly:
1. Set context **early** in `main()` before any logging
2. Configure file logging based on that context
3. Then each service would auto-generate unique log files based on `db_name`

### Current Workaround
Systemd handles log separation per service file:
```ini
StandardOutput=append:.../data-alchemy-local-bbocax-corporate_actions-1.0.log
StandardOutput=append:.../data-alchemy-local-bbocax-corporate_actions-2.0.log
```
