## DuckDB Worker Shards System

### Architecture

```
silver/YYYY/MM/DD/
├── {vendor}--{dataset}.sqlite              ← canonical DB
└── worker_dbs/
    ├── {vendor}--{dataset}_w001.sqlite     ← worker 1 shard
    ├── {vendor}--{dataset}_w002.sqlite     ← worker 2 shard
    └── {vendor}--{dataset}_w003.sqlite     ← worker 3 shard
```

### Per-Phase Flow

```
Phase Start  → DuckDB query canonical (clean, no shards)
Phase        → Workers write to w001, w002, ...
Phase End    → Merge shards → canonical → DELETE shards
```

### Key Design Decisions

1. **threading.local() for worker ID** (correct for ThreadPoolExecutor)
2. **UNION ALL Merge** (not sequential) - faster
3. **Empty Shard Handling** - check table exists before UNION ALL
4. **DELETE Journal Mode** (not WAL) - WAL doesn't work on NFS
5. **No Caching for Worker Shards** - they're deleted after each phase
6. **NullPool** - fresh connection each time, no stale state

### Graceful Shutdown Flow

1. Signal received → `_shutdown_requested = True`
2. Current file finishes, remaining skipped
3. Phase ends → **MERGE HAPPENS** (always)
4. Check `_shutdown_requested` → skip remaining phases
5. Exit gracefully

**Guarantee:** Processed files always merged before exit - no data loss on Ctrl+C or SIGTERM

### Common Errors

| Error | Cause | Fix |
|-------|-------|-----|
| `Table filemetadata does not exist` | Empty shard | Filter with `_shard_has_table()` |
| `attempt to write a readonly database` | NFS permissions | Check mount, permissions |
| `database is locked` | Lock contention | Worker shards eliminate this |

### Architecture

```
raw_pattern.jsonl          → Defines raw file patterns (pattern_id, directory, file_pattern)
raw_enriched_pattern.jsonl → Defines enriched file patterns
lineage_mapping.jsonl      → Links: raw_pattern_id → enriched_pattern_id → table_id
delta_table_repo.jsonl     → Maps table_id to table_name and repo_name
```

### 1. SQLite Race Condition (2026-03-14)
```python
# Before (db.py line 524-525)

    SQLModel.metadata.create_all(engine)

# After

inspector = inspect(engine)

    SQLModel.metadata.create_all(engine)
```
