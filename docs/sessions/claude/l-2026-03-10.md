## Command Templates

### Backfill with Separate Logs
```bash
source /home/svc_dat_alche_u/assets/staging/data-alchemy/.env && \
cd ~/assets/staging/data-alchemy/ && \
uv run python -m data_alchemy.main \
  --vendor {VENDOR} \
  --dataset {DATASET}_cwiq_pipe \
  --version 1.0 \
  --backfill 120 \
  -p 8 \
  --file-pattern '{PATTERN}' \
  --db-name "{vendor}--{ds}--{SUFFIX}" \
  --dq-targets "{TARGET_VENDOR}/{TARGET_DATASET}/{TARGET_VERSION}" \
  > >(tee /home/svc_dat_alche_u/assets/staging/logs/systemd/data-alchemy-staging-{vendor}-{dataset}-{suffix}.log) \
  2> >(tee /home/svc_dat_alche_u/assets/staging/logs/systemd/data-alchemy-staging-{vendor}-{dataset}-{suffix}-error.log >&2)
```
