### Shell Script Improvement Pattern (Discussed)

User showed improved shell script pattern — not applied yet, pending decision on scope:

```bash
#!/bin/bash
set -euo pipefail

# Save environment variables from systemd
_VENDOR="${VENDOR}"
_DATASET="${DATASET}"
_VERSION="${VERSION}"
_FILE_PATTERN="${FILE_PATTERN:-}"
_FILE_PATTERNS="${FILE_PATTERNS:-}"
_DB_NAME="${DB_NAME:-}"
_BACKFILL="${BACKFILL:-}"
_PARALLEL="${PARALLEL:-}"
_DQ_TARGETS="${DQ_TARGETS:-}"
_INTERVAL="${INTERVAL:-300}"

# Build optional arguments using bash array (safe for regex & spaces)
OPTIONAL_ARGS=()

if [[ -n "${_FILE_PATTERN}" ]]; then
    OPTIONAL_ARGS+=(--file-pattern "${_FILE_PATTERN}")
fi

if [[ -n "${_FILE_PATTERNS}" ]]; then
    IFS=',' read -ra PATTERNS <<< "${_FILE_PATTERNS}"
    for p in "${PATTERNS[@]}"; do
        OPTIONAL_ARGS+=(--file-patterns "${p}")
    done
fi

if [[ -n "${_DB_NAME}" ]]; then
    OPTIONAL_ARGS+=(--db-name "${_DB_NAME}")
fi

if [[ -n "${_BACKFILL}" ]]; then
    OPTIONAL_ARGS+=(--backfill "${_BACKFILL}")
fi

if [[ -n "${_PARALLEL}" ]]; then
    OPTIONAL_ARGS+=(--parallel "${_PARALLEL}")
fi

if [[ -n "${_DQ_TARGETS}" ]]; then
    IFS=',' read -ra TARGETS <<< "${_DQ_TARGETS}"
    for t in "${TARGETS[@]}"; do
        OPTIONAL_ARGS+=(--dq-targets "${t}")
    done
fi

# Load environment
source /home/svc_dat_alche_u/assets/staging/data-alchemy/.env

# Move to working directory
cd /home/svc_dat_alche_u/assets/staging/data-alchemy || exit 1

# Run Python service
exec uv run python -m data_alchemy.main \
    --watch \
    --interval "${_INTERVAL}" \
    --vendor "${_VENDOR}" \
    --dataset "${_DATASET}" \
    --version "${_VERSION}" \
    --staging "/sf/proj/data_alchemy/assets/prod/tree/${_VENDOR}-${_DATASET}-${_VERSION}-tree.json" \
    "${OPTIONAL_ARGS[@]}"
```

**Key improvements:**
- `set -euo pipefail` — strict error handling
- Bash arrays for OPTIONAL_ARGS — safer for regex & spaces
- `[[ ]]` instead of `[ ]` — modern bash syntax
- `exec` — replaces shell process
- Proper quoting throughout

### CLI Flags Reference

**File Pattern Flags:**
- `--file-pattern` (singular) — single regex pattern
- `--file-patterns` (plural) — multiple patterns, repeatable: `--file-patterns p1 --file-patterns p2`

**Parallel Processing:**
- `-p N` or `--parallel N` — number of workers
- `-p -1` — use all CPU cores

**Watch Mode:**
- `--watch` — continuous processing
- `--interval N` — seconds between cycles (default: 300)
