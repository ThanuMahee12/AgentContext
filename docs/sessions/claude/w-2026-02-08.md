### Session 2 (Afternoon) — CLI Refactor

#### 3. CLI Split into 3 Subcommands

**Commit:** `36a605b`

Refactored from 2 subcommands (scan with 6 mutually exclusive flags, compare) into 3 focused subcommands:

- `scan`: `-d`/`--dirs` or `-f`/`--files` (mutually exclusive, auto-detect .txt vs comma-sep)
- `delta`: positional `DELTA_CSV` arg (was `scan --delta-csv`)
- `compare`: `--source-prefix` + `--target-prefix` + `--subdirs` or `--files`

Added `_parse_input(value)` helper — if value ends with `.txt` and file exists, read lines; otherwise split on comma.

**Deleted:** `delta_result_main.py` (merged into delta subcommand), `_resolve_targets()` (replaced by `_parse_input()`)

#### 4. Output Directory Restructure

**Commit:** `1549ac3`

Changed output from `fs_hunter/YYYYMMDD_HHMMSS/` to `fs_hunter/{scan,delta,compare}/YYYYMMDD_HHMMSS/`. Updated `create_output_dir()` in utils.py to accept `subcommand` parameter.

#### 5. SHA256 → MD5 Hash

**Commit:** `0450a1f`

- Renamed `sha256` field to `md5` in FileMetadata dataclass
- `compute_hash()` uses `hashlib.md5()` in 8KB chunks (faster, sufficient for dedup)

#### 6. ENABLE_HASH Env Var + --off-hash Flag

**Commit:** `680a3f7`

- MD5 hash computed by default for all files
- `ENABLE_HASH` env var (default `true`) + `--off-hash` CLI flag
- Logic: `need_hash = (not off_hash) and enable_hash`
- `--file-pattern` takes two values: type + pattern (default: `glob *.parq*`)
