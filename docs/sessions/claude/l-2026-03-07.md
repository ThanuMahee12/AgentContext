## Fixes Implemented

### 1. SQL Injection Risk (Medium Risk) - Fixed
**File:** `duckdb_ops.py`

- Added `_validate_and_escape_path()` function
- Validates paths contain only safe characters (`[\w\-./\']+`)
- Rejects shell metacharacters (`$`, `;`, `|`, etc.)
- Escapes single quotes for SQL

```python
_SAFE_PATH_PATTERN = re.compile(r"^[\w\-./\']+$")

def _validate_and_escape_path(path: str) -> str:
    if not _SAFE_PATH_PATTERN.match(path):
        raise ValueError(f"Unsafe characters in path: {path}")
    return path.replace("'", "''")
```

### 2. NFS Race Condition - Fixed
**File:** `db.py:init_worker_shard_db()`

- Changed: Always call `SQLModel.metadata.create_all()` (idempotent)
- Avoids race where `os.path.exists()` sees partially-written file on NFS


### Critical Bug Fixes

#### 1. Silver(0/0) Bug - Fixed
**File:** `main.py:1018`

**Root Cause:** Discovery loop used wrong engine for mtime check. Variable `db_engine` was from previous loop iteration, not the correct engine for current file.

**Fix:** Added `file_to_db_engine` mapping to track correct engine per file.

```python
# Before (wrong engine)
if file_needs_reprocessing_by_mtime(db_engine, fp, "bronze"):

# After (correct engine per file)
file_to_db_engine: Dict[str, Engine] = {}
for file_path in files_to_process:
    current_db_path, current_engine = init_db(fp=file_path, ...)
    file_to_db_engine[file_path] = current_engine
...
fp_engine = file_to_db_engine.get(fp)
if fp_engine and file_needs_reprocessing_by_mtime(fp_engine, fp, "bronze"):
```

**Symptom:** Bronze reported 38 successful, but shards were empty → Silver found 0 files.

#### 2. Dedup Dropping Reprocessed Records - Fixed
**File:** `duckdb_ops.py:351-368`

**Problem:** `WHERE NOT EXISTS` dedup silently dropped reprocessed records (same input/stratum/output but updated timestamps).

**Fix:** Changed to DELETE + INSERT approach.

```python
# Step 1: Delete existing records that match incoming shard records
DELETE FROM canonical.filemetadata
WHERE (input_filepath, stratum, output_filepath) IN (
    SELECT input_filepath, stratum, output_filepath FROM ({union_query})
)

# Step 2: Insert all shard records
INSERT INTO canonical.filemetadata ... SELECT ... FROM ({union_query})
```
