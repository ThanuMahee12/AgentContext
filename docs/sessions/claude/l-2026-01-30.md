### 5. `--ignore-db` Flag Explanation

**Without `--ignore-db` (default):**
- Queries SQLite DB for processing status
- Skips files already marked as processed
- Only processes new files or files with newer mtime

**With `--ignore-db`:**
- Discovers files directly from disk
- Ignores DB state completely
- Processes ALL files found (within backfill window)
- Use for: full reprocess, DB out of sync, DB corrupted
