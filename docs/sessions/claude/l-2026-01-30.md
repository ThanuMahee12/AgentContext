### DQ Investigation - futures_extended Missing Files

**Issue**: DQ validation showed missing files for `back_office_futures_extended` 2.0 and 3.0

**Root Cause Found**: decrypt_inclusions missing patterns for `.px`, `.px.hpc`, `.rpx` files

**Bronze encrypted files exist:**
- `.dif.gz.enc` ✓ (was in inclusions)
- `.dlt.gz.enc` ✓ (was in inclusions)
- `.out.gz.enc` ✓ (was in inclusions)
- `.px.gz.enc` ✗ **MISSING from inclusions**
- `.px.hpc.gz.enc` ✗ **MISSING from inclusions**
- `.rpx.gz.enc` ✗ **MISSING from inclusions**

**Fix Applied**: Updated `resc/silver_decrypt_inclusions/bloomberg.json` lines 19-20:
```json
"shareFuturesExtended.*\\.(?:dif|out|dlt|px|px\\.hpc|rpx)\\.gz\\.enc",
"nonShareFuturesExtended.*\\.(?:dif|out|dlt|px|px\\.hpc|rpx)\\.gz\\.enc",
```

**Note**: `.csv` files are NOT encrypted (just `.csv.gz`), no decrypt pattern needed.
