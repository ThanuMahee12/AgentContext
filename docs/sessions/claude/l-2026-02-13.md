## Time Comparison Report

Script: `data_alchemy/utils/time_comparison_report.py`

### Quick Usage

```bash
# Last 4 hours (default)
source .env && uv run python -m data_alchemy.utils.time_comparison_report \
    --comparison-fp-prefix /sf/data \
    --vendor bloomberg --dataset best_cwiq_pipe --version 1.0

# Last 24 hours
source .env && uv run python -m data_alchemy.utils.time_comparison_report \
    --comparison-fp-prefix /sf/data \
    --vendor bloomberg --dataset bbocax_cwiq_pipe --version 1.0 \
    --hours 24

# Write to file
source .env && uv run python -m data_alchemy.utils.time_comparison_report \
    --comparison-fp-prefix /sf/data \
    --vendor bloomberg --dataset bbocax_cwiq_pipe --version 1.0 \
    --output /tmp/time_report.txt
```

### Flags

| Flag | Description |
|------|-------------|
| `--comparison-fp-prefix` | CDP reference path (e.g., `/sf/data`) |
| `--vendor` | Vendor name |
| `--dataset` | Dataset name |
| `--version` | Dataset version |
| `--hours` | Scan window (default: 4) |
| `--fp-prefix` | DA output prefix (default: `FP_PREFIX` env) |
| `--output` | Write to file |

- Services use `FILE_PATTERNS` (plural, comma-separated) or `FILE_PATTERN` (singular, regex)
